# 🦀 Rust Learning Lab

A personal repository dedicated to documenting my progress through the **[Rust Crash Course for Beginners](https://www.youtube.com/playlist?list=PLPoSdR46FgI412aItyJhj2bF66cudB6Qs)** by Francesco Ciulla.

## 🚀 Quick Start

1. **Update Toolchain:** `rustup update`
2. **Run a module:** `cd rust_learning && cargo run`

---

## 🛠 Rust Core Concepts

| Tool             | Description                                                 |
| :--------------- | :---------------------------------------------------------- |
| **rustup** | Installs/Updates Rust versions and components.              |
| **cargo**  | Package Manager: Handles builds, dependencies, and testing. |
| **rustc**  | The actual compiler running behind the scenes.              |
